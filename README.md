# C_Sharp_Events_CountdownTimer

## C#_Events_CountdownTimer

### Задание «Контрольная точка №22 — события, комплексное задание»[cite: 15]

Вариант 1. Таймер обратного отсчёта (понятнее)[cite: 15]
1. Класс CountdownTimer с событиями `event EventHandler<int>? Tick` (передаёт оставшиеся секунды) и `event EventHandler? Finished`[cite: 15].
2. Метод `Start(int seconds)`, на каждом шаге уменьшающий счётчик и вызывающий `Tick`, а при достижении нуля — `Finished`[cite: 15].
3. Подпишите на `Tick` минимум два обработчика: один просто выводит оставшееся время, второй должен отписаться от `Tick` сам, как только оставшееся время станет меньше половины от начального[cite: 15].
4. Подпишите на `Finished` обработчик, выводящий итоговое сообщение[cite: 15].
5. Продемонстрируйте полный запуск: видно, что второй обработчик `Tick` перестаёт срабатывать на середине отсчёта, первый — работает до конца, и `Finished` срабатывает один раз в конце[cite: 15].
